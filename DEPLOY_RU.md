# Деплой Сосед.Про в Timeweb Cloud (Apps + PostgreSQL) и привязка домена sosed.pro (NIC.RU)

Инструкция описывает запуск контейнера Next.js в **Timeweb Cloud Apps** с управляемой БД **PostgreSQL** в РФ. Названия кнопок в панели Timeweb могут немного отличаться: ориентируйтесь на смысл шага.

## 0. Перед запуском (требования законов РФ)

1. **Уведомление Роскомнадзора.** До начала обработки персональных данных оператор подаёт уведомление (ст. 22 152-ФЗ). Полученный регистрационный номер впишите в `src/config/company-legal.ts` (`roskomnadzorRegNumber`).
2. **Реквизиты ООО** впишите в `src/config/company-legal.ts`: они подставятся в подвал сайта и во все документы `/legal/*`.
3. **Юрист** должен проверить тексты `/legal/privacy`, `/legal/consent`, `/legal/offer-client`, `/legal/offer-master`: это шаблоны.
4. **Фото мастеров.** Файлы `public/avatars/alexey.jpg`, `elena.jpg`, `daniil.jpg` сейчас стоковые, замените их реальными фотографиями. Использование чужих портретов как «мастеров» вводит клиентов в заблуждение.
5. **Платежи и чеки.** Для приёма денег подключите платёжного оператора (Т-Банк или ЮKassa), настройте онлайн-кассу по 54-ФЗ и выплаты самозанятым.

## 1. Исходный код в репозитории

Timeweb Cloud Apps забирает код из репозитория (GitHub, GitLab или Bitbucket).

```bash
git init
git add .
git commit -m "Сосед.Про: первый деплой"
git remote add origin <адрес вашего приватного репозитория>
git push -u origin main
```

Файлы `.env`, `*.db` и `prisma/schema.local.prisma` в репозиторий не попадают (они в `.gitignore`).

## 2. Управляемая БД PostgreSQL

1. В панели Timeweb Cloud: **Облачные базы данных → Создать → PostgreSQL** (регион и дата-центр в РФ, например Москва).
2. Задайте имя БД, пользователя и пароль.
3. Если приложение и БД находятся в одной приватной сети проекта, используйте внутренний хост. Иначе разрешите доступ с IP приложения в настройках БД.
4. Соберите строку подключения:

```
postgresql://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@ХОСТ:5432/ИМЯ_БД?sslmode=require
```

Спецсимволы в пароле кодируются (`@` → `%40`, `#` → `%23`).

## 3. Приложение в Timeweb Cloud Apps

1. **Apps → Создать приложение → Docker** (деплой по `Dockerfile`).
2. Подключите репозиторий и ветку `main`. Путь к Dockerfile: `/Dockerfile`, контекст сборки: корень.
3. Порт приложения: **3000**.
4. Переменные окружения (раздел «Переменные»):

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка подключения из шага 2 |
| `AUTH_SECRET` | случайная строка от 32 символов (например, `openssl rand -base64 48`) |
| `NEXT_PUBLIC_SITE_URL` | `https://sosed.pro` (передаётся и как build-arg) |
| `NEXT_PUBLIC_METRIKA_ID` | номер счётчика Яндекс.Метрики (необязательно; также build-arg) |
| `SMSRU_API_ID` | ключ sms.ru для отправки кодов входа |
| `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` | приложение на oauth.yandex.ru (Redirect URI: `https://sosed.pro/api/auth/oauth/yandex`) |
| `BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Telegram-бот (необязательно) |
| `RUN_DB_PUSH` | `1` только на **первом** запуске: создаёт таблицы |
| `RUN_CATALOG_SEED` | `1` только на **первом** запуске: загружает города, прайс и коды ошибок |

Оставьте `AUTH_DEMO` пустым: в боевом режиме демо-вход выключен.

5. Нажмите **Развернуть**. После успешного старта уберите `RUN_DB_PUSH` и `RUN_CATALOG_SEED` и перезапустите приложение.

Проверка: `https://<адрес-приложения>/api/pricing` возвращает города и прайс, `/legal/privacy` открывается, `/login` присылает код на СМС.

> **Обновление схемы БД.** Сейчас таблицы создаёт `prisma db push`. Это удобно на старте, но перед ростом проекта переведите схему на миграции (`prisma migrate`), чтобы изменения применялись управляемо и без риска потерять данные.

## 4. Домен sosed.pro на NIC.RU

1. В Timeweb Apps откройте приложение → **Домены → Привязать домен** и введите `sosed.pro` (и `www.sosed.pro`). Панель покажет IP-адрес или CNAME, на который нужно направить домен.
2. В личном кабинете NIC.RU: **Мои домены → sosed.pro → DNS-серверы и управление зоной → Изменить зону → Добавить запись**.
3. Создайте записи:
   - тип **A**, имя `@`, значение: IP из панели Timeweb (если показан CNAME, используйте его для `www`, а для корня `@` возьмите A-запись по IP);
   - тип **CNAME**, имя `www`, значение: адрес из панели Timeweb (или `sosed.pro.`).
4. Сохраните зону. Распространение DNS занимает от нескольких минут до 24 часов.
5. Если домен делегирован на DNS Timeweb, записи нужно создавать в панели Timeweb, а не в NIC.RU. Проверьте текущие NS-серверы домена.
6. После обновления DNS в Timeweb Apps включите **бесплатный сертификат Let's Encrypt** для домена, чтобы сайт открывался по HTTPS. HTTPS обязателен: на нём работают вход и cookie `Secure`.

## 5. Хранение данных и локализация (152-ФЗ)

- Приложение и БД размещены у российского хостера: персональные данные граждан РФ хранятся в РФ.
- Сервис не обращается к зарубежным CDN: шрифты (`public/fonts`) и фото (`public/avatars`) отдаются с вашего сервера.
- Яндекс.Метрика подключается только после согласия на cookie.
- Включите автоматические резервные копии БД в Timeweb.

## 6. Локальная разработка

```bash
npm.cmd install        # создаст prisma/schema.local.prisma (SQLite) и сгенерирует Prisma Client
npm.cmd run setup      # база SQLite + демо-данные
npm.cmd run dev        # http://localhost:3000
```

`prisma/schema.prisma` — боевая схема PostgreSQL (единственный источник правды). Локальный файл `prisma/schema.local.prisma` создаётся из неё автоматически (меняется только `provider`), так что правки схемы делаются в одном месте.

Проверка Docker-образа локально (нужен Docker Desktop и доступный PostgreSQL):

```bash
docker build -t sosed-pro .
docker run --rm -p 3000:3000 -e DATABASE_URL="postgresql://..." -e AUTH_SECRET="..." -e RUN_DB_PUSH=1 -e RUN_CATALOG_SEED=1 sosed-pro
```
