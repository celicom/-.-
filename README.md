# Сосед.ру — MVP гиперлокального агрегатора бытовых услуг

«Uber для дома» в рамках ЖК: Клиент, Терминал мастера «Сосед.Про», Командный пункт CEO/CTO и серверное ядро в одном Next.js-приложении с общей базой и синхронизацией в реальном времени.

## Запуск

```bash
npm install
npm run setup   # создаёт SQLite-базу и заливает демо-данные
npm run dev     # http://localhost:3000
```

| Адрес | Модуль |
|---|---|
| `/client` | Клиентское PWA: диагностический пульт, калькулятор уборки, Клуб ЖК, гео-матчинг, эскроу, гарантийный талон |
| `/master` | Терминал «Сосед.Про» (Telegram WebApp): входящий вызов 30 сек, антифрод-чек-лист с фото ДО/ПОСЛЕ, Академия, кошелёк |
| `/admin` | Командный пункт: метрики ЖК, диспетчерская карта, сплит-эквайринг с чеками ФНС, ML-антифрод |
| `/api/ai-diagnostics` | GET — коды ошибок; POST — диагностика по коду/симптому |
| `/api/bot` | Вебхук Telegram и статус бота |
| `/api/match?skill=coffee` | Гео-матчинг мастеров |
| `/api/stream` | SSE-поток изменений для всех окон |

Кнопка **«3 окна рядом»** в верхней панели открывает Клиента, Мастера и Админа одновременно. **«Сброс»** возвращает демо-данные.

## Сценарий показа

1. Клиент → Ремонт → Бытовая техника → Кофемашины → Jura → **Error 8** → «Вызвать мастера».
2. У Мастера (Рафаэль) звучит входящий вызов с ИИ-подсказкой «что положить в сумку» → «Принять заказ».
3. Клиент видит мастера на карте. Мастер: «Я на месте» → чек-лист → фото ДО → смета.
4. Клиент согласует смету. Мастер: фото ПОСЛЕ → кнопка выплаты разблокируется.
5. Клиент подтверждает → эскроу размораживается, в Админке появляется сплит платежа и чек ФНС, клиент получает гарантийный талон.
6. Админка → ML-антифрод: у Алексея 45% «отказов» — заблокировать или списать штраф из депозита.

## Telegram-бот

1. Получите токен у [@BotFather](https://t.me/BotFather) и вставьте в `.env`: `BOT_TOKEN="..."`.
2. `npm run bot` → напишите боту `/start`, он пришлёт ваш chat id.
3. Вставьте его в `.env` как `TELEGRAM_CHAT_ID` и перезапустите `npm run dev`.

Код бота — в `telegram-bot.ts` (нативный fetch к Bot API). Пока токена нет, уведомления пишутся в журнал Админки.

## Переход на Supabase / PostgreSQL

В `prisma/schema.prisma` замените `provider = "sqlite"` на `"postgresql"`, в `.env` укажите строку подключения Supabase и выполните `npm run setup`.
